# Infraestructura y tecnologías

## Servidores

- **Nginx** — Servidor web y proxy inverso para servir aplicaciones, gestionar tráfico HTTP/HTTPS y distribuir peticiones.
- **Linux** — Sistema operativo habitual para ejecutar servidores, aplicaciones y servicios de infraestructura.

## BBDD

- **MySQL 8.x** — Sistema gestor de bases de datos relacionales para almacenar y consultar información estructurada.
- **Percona Server for MySQL** — Distribución optimizada de MySQL orientada a rendimiento, disponibilidad y administración de bases de datos.
- **PostgreSQL** — Base de datos relacional avanzada utilizada para aplicaciones que requieren consultas complejas, integridad y extensibilidad.

## NO-SQL

- **Redis** — Almacén de datos en memoria utilizado principalmente para caché, sesiones, colas y operaciones de baja latencia.
- **MongoDB** — Base de datos documental NoSQL orientada a almacenar información flexible mediante documentos JSON/BSON.

## AMAZON AWS

- **Amazon Redshift** — Data warehouse cloud para analizar grandes volúmenes de datos mediante SQL.
- **Amazon S3** — Almacenamiento de objetos para documentos, ficheros, copias de seguridad y datos.
- **Amazon EC2** — Servicio de máquinas virtuales para ejecutar aplicaciones y servicios en AWS.
- **Amazon RDS** — Servicio gestionado para desplegar y administrar bases de datos relacionales.
- **Amazon CloudFront** — CDN de AWS para distribuir contenido desde ubicaciones próximas al usuario.
- **AWS Lambda** — Ejecución de código bajo demanda sin necesidad de administrar servidores.
- **Amazon CloudWatch** — Monitorización de aplicaciones, servidores, métricas, logs y alertas.

## CDN

- **Akamai** — Red de distribución de contenido para acelerar sitios web, aplicaciones y servicios digitales.
- **Cloudflare** — CDN y plataforma de seguridad para proteger y acelerar aplicaciones y sitios web.
- **Amazon CloudFront** — CDN integrada con AWS para distribuir contenido globalmente.

# Lenguajes y frameworks

## WEBSITE + BACKEND TOOLS

- **PHP 8.x** — Lenguaje utilizado para desarrollar aplicaciones web y servicios backend.
- **Phalcon** — Framework PHP orientado a aplicaciones web de alto rendimiento; tecnología heredada del stack original.
- **Laravel** — Framework PHP moderno para desarrollar aplicaciones web, APIs y servicios backend.
- **Symfony** — Framework PHP modular utilizado para construir aplicaciones empresariales y servicios web.
- **Twig** — Motor de plantillas para generar interfaces HTML de forma estructurada y segura.
- **JavaScript** — Lenguaje principal para desarrollar funcionalidades dinámicas en el navegador.
- **TypeScript** — Extensión tipada de JavaScript utilizada para desarrollar aplicaciones frontend y backend más mantenibles.
- **jQuery** — Biblioteca JavaScript para manipulación del DOM y compatibilidad; actualmente considerada tecnología legacy en muchos proyectos.
- **React** — Biblioteca para construir interfaces web mediante componentes reutilizables.
- **Vue.js** — Framework progresivo para desarrollar interfaces web interactivas.
- **Node.js** — Entorno de ejecución de JavaScript utilizado para servicios backend, herramientas y aplicaciones web.
- **Vite** — Herramienta moderna de desarrollo y compilación para aplicaciones frontend.

## iOS APPs

- **Swift** — Lenguaje principal de Apple para desarrollar aplicaciones para iOS, iPadOS, macOS y otros sistemas Apple.
- **SwiftUI** — Framework declarativo de Apple para construir interfaces de usuario multiplataforma.
- **Xcode** — Entorno oficial de Apple para desarrollar, probar y distribuir aplicaciones.
- **Objective-C** — Lenguaje utilizado históricamente en aplicaciones Apple y todavía presente en proyectos heredados.
- **XCTest** — Framework de Apple para realizar pruebas unitarias y de interfaz.

## ANDROID APPs

- **Kotlin** — Lenguaje recomendado por Google para desarrollar aplicaciones Android modernas.
- **Java** — Lenguaje ampliamente utilizado en aplicaciones Android existentes y proyectos heredados.
- **Jetpack Compose** — Framework declarativo moderno para construir interfaces Android.
- **Android Studio** — Entorno oficial para desarrollar, depurar y probar aplicaciones Android.
- **Android Jetpack** — Conjunto de bibliotecas que facilita el desarrollo de aplicaciones Android mantenibles y compatibles.

## BACKEND TASKS

- **Python** — Lenguaje utilizado para automatización, procesamiento de datos, servicios backend e inteligencia artificial.
- **PowerShell** — Lenguaje de automatización y administración de sistemas especialmente utilizado en entornos Windows.
- **Bash** — Shell utilizado para automatización, administración de servidores Linux y ejecución de tareas.
- **Celery** — Sistema de procesamiento distribuido para ejecutar tareas asíncronas y programadas en Python.
- **Cron** — Sistema de planificación utilizado para ejecutar tareas automáticamente en sistemas Linux.

## REST APIs

- **REST** — Arquitectura para desarrollar servicios web accesibles mediante HTTP.
- **OpenAPI** — Especificación para describir, documentar y probar APIs.
- **PHP / Laravel** — Stack utilizado para desarrollar APIs REST modernas en PHP.
- **Symfony** — Framework para desarrollar APIs y servicios backend empresariales.
- **FastAPI** — Framework Python orientado al desarrollo de APIs de alto rendimiento.
- **OAuth 2.0** — Estándar para autorización y acceso seguro a APIs.
- **JWT** — Formato de tokens utilizado para transmitir información de autenticación y autorización.

# Herramientas y servicios

## Analítica

- **Google Analytics 4** — Plataforma de analítica para medir tráfico, usuarios, eventos y conversiones de sitios web y aplicaciones.
- **Amplitude** — Plataforma de analítica de producto para estudiar comportamiento, eventos y recorridos de usuarios.
- **Smartlook** — Herramienta de análisis de comportamiento mediante sesiones, eventos y mapas de interacción.
- **Google Tag Manager** — Sistema para gestionar etiquetas y scripts de analítica y marketing sin modificar directamente el código de la aplicación.

## Monitorización

- **Ansible** — Plataforma de automatización para configurar servidores, desplegar aplicaciones y ejecutar tareas de administración.
- **Prometheus** — Sistema de monitorización y recopilación de métricas de infraestructura y aplicaciones.
- **Grafana** — Plataforma para visualizar métricas, crear dashboards y configurar alertas.
- **ELK / Elastic Stack** — Conjunto de herramientas para recopilar, buscar, analizar y visualizar logs.
- **Sentry** — Plataforma para detectar, monitorizar y diagnosticar errores de aplicaciones.

## Virtualización y contenedores

- **Docker** — Plataforma para empaquetar y ejecutar aplicaciones en contenedores aislados.
- **Docker Compose** — Herramienta para definir y ejecutar aplicaciones formadas por múltiples contenedores.
- **Kubernetes** — Plataforma para orquestar, escalar y administrar aplicaciones contenerizadas.
- **Vagrant** — Herramienta para crear y administrar entornos virtualizados reproducibles, especialmente útil en desarrollo.
- **Terraform** — Herramienta de Infrastructure as Code para crear y gestionar infraestructura mediante configuración declarativa.

## CI/CD

- **Git** — Sistema de control de versiones para gestionar el código fuente y el historial de cambios.
- **GitHub** — Plataforma para alojar código, colaborar y automatizar procesos de desarrollo.
- **GitLab** — Plataforma DevOps para gestionar código, integración continua y despliegues.
- **GitHub Actions** — Sistema de automatización para ejecutar pruebas, compilaciones y despliegues.
- **Jenkins** — Servidor de automatización utilizado para implementar procesos CI/CD.

## Seguridad

- **TLS/HTTPS** — Protocolos utilizados para cifrar las comunicaciones entre clientes y servidores.
- **Let's Encrypt** — Autoridad de certificación que proporciona certificados TLS gratuitos.
- **OWASP** — Referencia de buenas prácticas y riesgos de seguridad en aplicaciones web.
- **HashiCorp Vault** — Sistema para gestionar de forma segura secretos, credenciales y claves.

# Metodología

- **Scrum** — Marco ágil para organizar el desarrollo mediante iteraciones, prioridades y entregas incrementales.
- **Kanban** — Metodología visual para gestionar el flujo de trabajo y limitar tareas en curso.
- **DevOps** — Cultura y conjunto de prácticas que integran desarrollo, operaciones, automatización y despliegue.
- **CI/CD** — Automatización de pruebas, integración, construcción y despliegue del software.
- **GitFlow** — Estrategia de organización de ramas Git para coordinar desarrollo, versiones y releases.
